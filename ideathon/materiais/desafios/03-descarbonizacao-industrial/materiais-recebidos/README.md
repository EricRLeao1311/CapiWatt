# Materiais recebidos - Descarbonização industrial

A organização não anexou uma base específica para este desafio na pasta pública consultada. O caderno autorizou o uso de dados públicos e indicou os tipos de informação que devem ser procurados:

- indicadores operacionais e consumo energético;
- características dos processos e equipamentos;
- fatores de emissão;
- informações públicas de instalações industriais.

O arquivo `fontes-indicadas-no-caderno.md` registra esse direcionamento. As fontes externas efetivamente encontradas estão em `../materiais-encontrados/` para manter clara a diferença entre material entregue e pesquisa da equipe.
