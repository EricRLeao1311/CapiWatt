# Materiais recebidos - Demanda energética

Materiais entregues pela organização na pasta pública **ERA5 - Tutorial Demanda energética**:

- `Acesso ao ERA 5.pdf`: instruções de acesso aos dados meteorológicos.
- `ERA5_Land_passo_a_passo.ipynb`: notebook com exemplo de consulta e manipulação.

Os arquivos estão em `tutorial-era5/ERA5 - Tutorial Demanda energética/`.

O ERA5 não é uma medição direta: trata-se de uma reanálise que combina observações e modelos. Registre variáveis, resolução espacial, fuso horário e método de associação com a carga elétrica.
