# Ideathon

## Treinamentos

Gravações organizadas por data, com link de origem, espaço para vídeo, transcrição e resumo provisório. Resumos elaborados só a partir da agenda estão identificados como preliminares.

## Materiais

O [Caderno de Desafios e Dados](materiais/Caderno_de_desafios_e_dados.pdf) orienta seis pastas de desafio. Cada uma contém resumo, áreas para dados recebidos e materiais externos, e um PowerPoint de canvas para estruturar a proposta.
