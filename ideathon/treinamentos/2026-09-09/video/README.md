# Vídeo baixado

Arquivo de vídeo ainda não disponível neste repositório. Baixe a gravação pelo link oficial: https://www.youtube.com/watch?v=oK-dnEmuE2I

Sugestão com `yt-dlp` instalado:

```powershell
yt-dlp -o "video.%(ext)s" "https://www.youtube.com/watch?v=oK-dnEmuE2I"
```

A gravação permanece vinculada à plataforma de origem; confira os termos e a disponibilidade antes de redistribuí-la.
